## Qual destes é um tipo de pacote correto em Go?
* Pacote vazio
* Pacote executável *CORRETA*
* Pacote transferível
* Pacote bibliotecário

## Que tipo de pacote o `go run` consegue executar?
* Pacote vazio
* Pacote executável *CORRETA*
* Pacote transferível
* Pacote de biblioteca

## Que tipo de pacote o `go build` consegue compilar?
* Pacote vazio
* Pacote temporário
* Tanto pacotes executáveis quanto de biblioteca *CORRETA*
* Pacote transferível

## Qual destes é um pacote executável?
* `package main` com `func main` *CORRETA*
* `package Main` com `func Main`
* `package exec` com `func exec`

## Qual destes é um pacote de biblioteca?
* `main package`
* `package lib` *CORRETA*
* `func package`
* `package main` com `func main`

## Que pacote é usado para um programa Go executável?
* Pacote vazio
* Pacote executável *CORRETA*
* Pacote transferível
* Pacote de biblioteca

## Que pacote é usado para reutilização e pode ser importado?
* Pacote vazio
* Pacote executável
* Pacote transferível
* Pacote de biblioteca *CORRETA*
