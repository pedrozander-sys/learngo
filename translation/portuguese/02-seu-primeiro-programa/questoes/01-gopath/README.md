## Onde você deve salvar o seu código-fonte Go?
* Em qualquer lugar do meu computador
* Dentro de $GOPATH
* Dentro de $GOPATH/src *CORRETA*

## O que significa $GOPATH?
* É um arquivo para o runtime do Go
* Guarda arquivos de código-fonte Go e pacotes compilados
* É um caminho para os gophers seguirem

## Você precisa definir o $GOPATH?
* Sim
* Não: ele fica na minha área de trabalho
* Não: ele fica no caminho do meu usuário *CORRETA*

## Como você pode imprimir o $GOPATH?
* Usando o comando `ls`
* Usando o comando `go env GOPATH` *CORRETA*
* Usando o comando `go environment`
