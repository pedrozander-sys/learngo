# Muitos exemplos, exercícios e questionários de Go

A melhor forma de aprender é praticando. Neste repositório você vai encontrar milhares de exemplos, exercícios e questionários de Go. Criei este repositório originalmente para o meu **[Go: Bootcamp Course](https://www.udemy.com/course/learn-go-the-complete-bootcamp-course-golang/?referralCode=5CE6EB34E2B1EF4A7D37)**. Depois, adicionei muitos exercícios e quis que todo programador que ainda não está inscrito no curso também pudesse aprender de graça. Então, aqui está. Aproveite.
